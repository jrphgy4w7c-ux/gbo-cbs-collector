# Front Office Artifact Registry

This registry controls which durable artifacts may be treated as current institutional evidence.

## Mandatory supersession rule

- Before using any versioned Front Office OS, GFO Control Center, GBO control workbook, or similar durable artifact, determine whether a later version exists.
- A superseded artifact may be consulted only to understand historical architecture/version evolution. It must not supply current institutional facts, corrections, authority rules, or active doctrine when a later version supersedes it.
- If a superseded artifact contains a known factual or interpretive error, that error remains quarantined even if semantic/file search retrieves the older file more prominently than the corrected version.
- Current platform state still controls platform-recorded facts for its effective timestamp; durable artifacts control only the institutional/history domains they are explicitly authoritative for.
